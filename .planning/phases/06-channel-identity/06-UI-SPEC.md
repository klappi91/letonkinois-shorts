## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tag padding, badge inline padding |
| sm | 8px | Card internal spacing, compact label padding |
| md | 16px | Default element spacing, grid gaps on mobile |
| lg | 24px | Section padding, moodboard card gap |
| xl | 32px | Layout-level padding, page container vertical rhythm |
| 2xl | 48px | Major section breaks, page header bottom margin |
| 3xl | 64px | Page-level vertical spacing |

Exceptions:
- Instagram Safe Zone top: 140px (`SAFE_ZONES.topSafe`) — below Instagram UI chrome
- Instagram Safe Zone bottom: 380px (`SAFE_ZONES.bottomSafe`) — above caption + like buttons
- Instagram Safe Zone sides: 60px (`SAFE_ZONES.sideSafe`) — horizontal edges
- Instagram content inner margin: 80px (`SAFE_ZONES.contentSide`) — inner text margin
- Touch targets minimum: 44px height on all interactive elements in /moodboard

Source: RESEARCH.md (Memory: feedback_reel_composition_template.md safe zone values 140 / 380 / 60 / 80); touch target from accessibility standard.

**Accent (#B50606) reserved exclusively for:**

Accent is NOT used for: backgrounds larger than 32x32px, full-width buttons, section fills, or decorative elements.

### Color Grading (Golden-Hour CSS Filter)

Applied via `<ColorGrade>` wrapper at composition root in Remotion:

| Filter | Value | Effect |
|--------|-------|--------|
| sepia | 0.15 | Slight warm sepia tint |
| saturate | 1.2 | Richer, warmer colors |
| brightness | 1.05 | Slight lift, not washed out |
| contrast | 1.08 | Micro contrast boost |
| hue-rotate | 5deg | Warm shift toward amber |

**CSS filter string:** `sepia(0.15) saturate(1.2) brightness(1.05) contrast(1.08) hue-rotate(5deg)`

Note: These are starting values (LOW confidence, per RESEARCH.md). They must be validated visually in Remotion Studio before being frozen. The planner includes a "tune in Studio" task before the 5-image validation task.

Source: CONTEXT.md (D-05, D-06, D-07); RESEARCH.md (Pattern 3, car-detailing-aesthetic-transfer.md).

  id: string;

## Implementation Notes for Executor

1. **Write `brand.ts` first.** Validate both `npm run build` (root) and `cd remotion && tsc --noEmit` compile before touching any component files.

2. **ColorGrade at composition root only.** Apply `<ColorGrade>` as the outermost wrapper of a composition function — never inside individual `<Sequence>` children. Stacking on transitions causes double-grading.

3. **fonts.ts is exempt from re-export migration.** `loadFont` calls from `@remotion/google-fonts` must remain in `remotion/src/utils/fonts.ts`. The `FONTS` constant in `brand.ts` stores font names as plain strings for Gemini prompts and reference only.

4. **globals.css receives navy + sync comment.** Add `--color-navy: #1A2744` to the @theme block. Add a comment: `/* MANUELLER SYNC AUS src/lib/brand.ts — zuletzt synchronisiert 2026-03-28 */`. Do NOT remove wood-amber/honey/walnut tokens — they are valid dashboard-only tokens.

5. **Moodboard screenshots are static files.** `public/assets/moodboard/` must be created and populated with 5+ manually saved screenshots before `moodboard.ts` data entries reference them.

6. **COLOR_GRADE values need visual tuning.** Starting values (sepia 0.15, saturate 1.2, brightness 1.05, contrast 1.08, hue-rotate 5deg) must be validated in Remotion Studio. Adjust until the look matches "warm golden afternoon, not oversaturated."
