2. Create seed script with these exact imports and logic:

```typescript
import { createAdminClient } from '../src/lib/supabase/admin'
import videosJson from '../src/data/videos.json'

interface VideoJsonEntry {
  id: string
  title: string
  type: string
  createdAt: string
  videoFile: string
  duration: number
  captionDe: string
  captionFr?: string
  hashtags: string[]
  rating: string
  products?: string[]
  pipeline: string
}

async function seed() {
  const supabase = createAdminClient()

  const rows = (videosJson as VideoJsonEntry[]).map((entry) => ({
    id: entry.id,
    title: entry.title,
    type: entry.type,
    created_at: entry.createdAt,
    video_url: entry.videoFile,
    duration: entry.duration,
    caption_de: entry.captionDe,
    caption_fr: entry.captionFr ?? null,
    hashtags: entry.hashtags,
    status: entry.rating === 'pending' ? 'draft' : entry.rating,
    products: entry.products ?? [],
    pipeline: entry.pipeline,
    prompt_version: null,
  }))

  const { data, error } = await supabase.from('videos').upsert(rows)
  if (error) {
    console.error('Seed failed:', error)
    process.exit(1)
  }
  console.log(`Seeded ${rows.length} videos successfully.`)
}

seed()
```

CRITICAL field mapping (from Research Pattern 7):
- `createdAt` -> `created_at` (camelCase to snake_case)
- `videoFile` -> `video_url` (rename)
- `captionDe` -> `caption_de` (camelCase to snake_case)
- `captionFr` -> `caption_fr` (camelCase to snake_case, undefined -> null)
- `rating: "pending"` -> `status: "draft"` (MUST map — "pending" violates CHECK constraint)
- `products` -> `products` (undefined -> empty array)
- `prompt_version` -> `null` (not in JSON)

3. Uses `upsert` so the script is idempotent (safe to re-run)
4. Uses `createAdminClient()` to bypass RLS during seeding
