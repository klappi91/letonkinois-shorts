    - Render 5 star buttons using Unicode `★` character
    - Each button: `type="button"`, `onClick={() => setStars(n)}`
    - Filled stars (n <= stars): `text-brand-red` class
    - Empty stars (n > stars): `text-text-muted` class
    - Hover effect: `hover:text-brand-red`
    - Wrap in `<div role="group" aria-label="Sternebewertung">` for accessibility
    - Each button: `aria-label={\`${n} Stern${n > 1 ? 'e' : ''}\`}`
    - Star size: `text-2xl`

    **Textarea fields (per D-08):**
    - Pros textarea: label "Was gefaellt dir?", id="pros", placeholder "Was hat dir besonders gefallen?"
    - Cons textarea: label "Was koennte besser sein?", id="cons", placeholder "Was wuerde das Video verbessern?"
    - Both: `rows={3}`, `resize-none` class
    - Styling: same as login page inputs: `w-full px-3 py-2 rounded-lg border border-bg-sepia bg-bg-card text-text-dark text-sm focus:outline-none focus:ring-2 focus:ring-brand-red/30 focus:border-brand-red`

    **Submit handler (per D-03, D-04):**
    - Validate `stars > 0` before submitting — if 0, set error "Bitte waehle eine Sternebewertung"
    - Call `createClient()` from `@/lib/supabase/client`
    - Call `supabase.auth.getUser()` (never getSession — per STATE.md decision)
    - Call `.upsert()` with `{ video_id: videoId, user_id: user!.id, stars, pros: pros || null, cons: cons || null }` and `{ onConflict: 'video_id,user_id' }` (per D-03)
    - Do NOT set `processed_at` — it stays null (per D-11)
    - On success: `window.location.reload()` (per D-04)
    - On error: set error "Fehler beim Speichern"
    - Catch block: set error "Verbindungsfehler — bitte erneut versuchen"

    **Submit button (per D-09):**
    - Label: "Bewertung speichern" (not "Absenden")
    - Loading label: "Speichern..."
    - Styling: `w-full py-2.5 rounded-lg bg-brand-red text-white font-bold text-sm hover:bg-brand-red-hover transition-colors disabled:opacity-50`
    - `disabled={loading || stars === 0}`

    **Error display:**
    - Same pattern as login page: `<p className="text-sm text-brand-red mb-4">{error}</p>`
